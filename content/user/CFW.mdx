# User Handbook - Custom Firmware (CFW)

At the moment of writing, we do not support CFW such as Atmosphere 2, due to:

- The Switch 2 not having (public) custom firmware.

- Atmosphere 2 not existing yet as of writing this.

We do however, theoretically maintain HLE compatibility with the former mentioned CFW, and applications that require Atmosphere to run would maybe run fine in the emulator without any adjustments in practice.
